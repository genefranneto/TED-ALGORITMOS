# Sistema de Biblioteca (BibliotecaNova)

Trabalho de faculdade (TED de Algoritmos): um sistema de biblioteca em modo console, feito em C# (.NET).

## Autores

- Genefran Alves Thomaz Neto
- Marilia Lima da Silva

## Funcionalidades

1. Cadastrar livro
2. Listar livros
3. Buscar livro
4. Ordenar livros
5. Listar livros disponíveis
6. Emprestar livro
7. Devolver livro
0. Sair

## Como executar

Com o .NET SDK instalado, dentro da pasta `BibliotecaNova`:

```bash
dotnet run
```
